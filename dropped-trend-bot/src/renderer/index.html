쿠팡 파트너스 링크 생성

쿠팡 파트너스 API 승인 전까지 일반 Chrome의 Dropped Link Helper를 사용합니다.

현재 사용방법

상품 선택 → 파트너스 준비 → Chrome에서 쿠팡 파트너스 간편링크 페이지 → Dropped Link Helper 실행

선택한 상품목록은 자동으로 클립보드에 복사됩니다.

각 트렌드의 대표상품 #1만 기본 선택합니다. #2~#5는 필요할 때 수동으로 추가하세요.
