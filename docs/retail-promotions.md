# 마트·편의점 행사 운영

- `/store-deals`: 실제 가격을 확인한 품목의 내부 목록. 필터 URL을 새로고침·뒤로가기와 공유에 사용한다.
- `/store-deals/[id]`: 동일 상품의 행사 수량·결제 총액·조건과 직접 관측한 기록. 표시 할인율과 실제 이전 가격은 구분한다.
- 공식 상품 사진·전단·리뷰는 복제하지 않는다. 상품명·가격·기간과 직접 계산한 수량 비교만 제공한다.
- 수집 저장소: 기존 `jmh7739/dropped`의 `marketbot-collectors/collect_retail_promotions.py`, `marketbot-data/retail-promotions.json`.
- 기존 public-data 워크플로의 6시간 주기에 연결했다. 새 키·새 스케줄러·제휴 태그는 없다. Site는 30분 캐시로 조회하고 실패하면 날짜가 붙은 빌드 시점 관측본을 사용한다.
- CU: 공개 행사 목록 각 2페이지에서 목록/상세의 이름·가격·증정 조건을 대조한다. 종료일은 제공되지 않아 추정하지 않는다.
- 홈플러스: 공개 디지털 전단 목록/상세의 상품명·숫자 가격·기간을 대조한다. 회원·판매 단위·취급 점포 조건을 유지한다. 인쇄 전단과 모순되는 기준가격은 이전 가격으로 쓰지 않는다.
- robots의 명시적 금지, 인증·권한·속도 제한과 실패를 우회하지 않는다. robots만 400/404/410인 경우는 RFC 9309 §2.3.1.3의 unavailable로 구분하되 본문 4xx는 여전히 중단한다. 5xx·정책 HTML·연결 실패도 중단한다. UA는 MarketBot로 고정한다.
- 롯데마트 등은 구조화 가격의 확인이 끝나지 않아 공식 안내를 보조로 제공한다. 노브랜드는 전문점/이마트 내 상품을 같은 행사로 간주하지 않는다.
- 48시간 지난 관측은 현재 목록에서 제외한다. 사라진 상품을 종료일 없이 임의 종료로 만들지 않는다. 명시된 기간이 끝난 것은 종료 기록에서 조회한다.
- 같은 날 같은 조건은 마지막 확인 1건으로 합치며, 조건 변경과 실제 날짜별 기록을 보존한다. 스케줄 동시 갱신은 최신 관측과 이력을 병합한다.
- 알려진 보류: 홈플러스 `2645`, 2026-10-15~21 국물용 멸치 500G는 디지털 가격과 인쇄 전단의 가격이 달라 공개 목록·상세에서 제외한다. 원시 관측은 감사용으로 보존한다. 수집기와 `isPublishableRetailOffer`에 기간을 한정한 보류가 있다.
- 관심 상품·브랜드·장보기는 localStorage, 방문 중 비교 기준은 sessionStorage를 사용한다. 다른 저장 키를 지우지 않으며 자동 알림·계정 동기화는 없다.
- 검증: `python -m unittest discover -s marketbot-collectors -p test_retail_promotions.py` (수집 저장소), `node scripts/test-retail.cjs`, `npm test`, `npx tsc --noEmit`, `npm run build`.
- 모바일/PC Playwright 실제 UI 검수와 결과 스크린샷은 작업공간 `.codex-audit/retail-20261021`에 보존한다. 실기기 검수와 구분한다.
